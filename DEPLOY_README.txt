WellOne Order Receiving v93 — old working admin connection reference

Deploy the CONTENTS of this folder to the order receiving site root.
Do not mix v93 files with v89-v92 files.

After deployment:
1. Close every old Order Receiving tab/PWA window.
2. Reopen the site.
3. If an installed PWA still shows an old v89-v92 error, remove that installed PWA/site data once and reopen the deployed site.

No new SQL is required by v93.
